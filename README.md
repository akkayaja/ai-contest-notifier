# 🏆 AI 대회 알리미

> 매주 월요일 아침, 새로 올라온 **AI 해커톤·공모전**을 골라 **카카오톡**으로 요약해 주는 자동 알림.
> 코드 한 줄 없이, **한국어 지시문 + Claude Code 클라우드 루틴**만으로 만들었습니다.

## 왜 만들었나

- AI·데이터 공모전 정보가 링커리어, 위비티, 콘테스트코리아, 올콘 등 여러 사이트에 흩어져 있다.
- **참가 자격(나이·직장인 가능 여부)**과 **창업·사업화 필수 여부**를 매번 공고문에서 직접 확인해야 했다.
- 이미 본 대회를 또 보고, 마감을 놓치는 일이 반복됐다.

## 무엇을 하나

| 기능 | 설명 |
|---|---|
| 🔎 수집 | 공모전 사이트 4곳 + 웹 검색에서 AI·데이터·해커톤·공공데이터·업무자동화 대회 탐색 |
| 🧹 필터 | 일반인·직장인 참가 가능 / 창업·사업화 필수, 학생 전용, 마감 지난 대회 제외 |
| 🔥 강조 | 접수 마감 **2주 이내**는 맨 위에 |
| ⭐ 우대 | **채용 연계·전형 면제**, **비개발자(기획 부문) 참가 가능** 대회 표시 |
| 🔁 중복 제거 | 보낸 대회를 `알린_대회목록.json`에 기록 → 다음 주엔 다시 안 보냄 |
| 💬 알림 | 카카오톡 "나와의 채팅"으로 대회별 1메시지 (메시지당 200자 제한 대응) |

## 어떻게 동작하나

```
매주 월 08:00 (KST)
      │
      ▼
Claude Code 클라우드 루틴 ── 이 저장소를 내려받음
      │
      ├─ 지시문.md 읽기 (조건·규칙)
      ├─ 알린_대회목록.json 읽기 (이미 보낸 대회)
      ├─ 공모전 사이트·웹 검색으로 새 대회 찾기
      ├─ 카카오톡 "나와의 채팅"으로 요약 발송
      └─ 보낸 대회를 기록 → 저장소에 커밋 & push
```

- **컴퓨터가 꺼져 있어도** 클라우드에서 실행됩니다.
- 조건을 바꾸고 싶으면 [`지시문.md`](지시문.md)만 고쳐서 push 하면 다음 주부터 반영됩니다.

## 설계에서 고민한 것

**1. 크롤링 코드 vs AI 예약 작업**
파이썬 크롤러는 무료·빠르지만 사이트 구조가 바뀌면 고장 나고, "창업 필수인지" 같은 판단을 코드로 짜기 어렵다.
초보자도 유지할 수 있도록 **자연어 지시문 + Claude 루틴**을 택했다.

**2. 사이트 이용 규칙 준수**
- 각 사이트의 `robots.txt`를 직접 확인 — 4곳 모두 공모전 목록 자동 접근 허용
- 공개 페이지만, 주 1회, 사이트당 최대 10페이지
- 공고 전문 복사 없이 **요약 + 원문 링크**만
- 접근이 막히면 우회하지 않고 건너뛰고 "접속불가"로 표시

**3. 최소 권한**
- 루틴에 자동으로 붙은 커넥터(Vercel, Supabase 등)를 제거하고 **카카오톡만** 남김
- 클라우드 네트워크도 **대회 사이트 도메인만** 허용

**4. 환각 방지**
- 확인 못 한 정보는 지어내지 않고 **"확인필요"**로 표시
- 모든 대회에 원문 링크 첨부 → 최종 확인은 사람이

## 시행착오

| 문제 | 원인 | 해결 |
|---|---|---|
| 첫 실행이 "새 대회 없음"으로 43초 만에 종료 | 클라우드 환경 기본 네트워크가 대회 사이트를 차단 | 환경 설정에서 대회 사이트 도메인 허용 |
| 사이트를 열지 않고 검색 요약만 보고 끝냄 | 지시문에 "직접 확인" 의무가 없었음 | 4개 사이트 목록 페이지를 **반드시 직접 열도록** 지시문 보강 |
| 자격이 불분명한 대회를 아예 빼 버림 | "확인필요" 처리 기준이 모호 | 제외 조건에 명확히 해당하지 않으면 **"자격: 확인필요"로 보내도록** 명시 |
| 카톡 머리말 날짜가 예시 날짜(11/16)로 고정 | 지시문 예시를 그대로 복사 | 예시를 `MM/DD`로 바꾸고 "실행 날짜로 쓴다" 명시 |

**결과:** 두 번째 실행에서 조건에 맞는 대회 **9건**을 찾아 카톡 10개 메시지로 발송하고, 기록 파일이 저장소에 자동 커밋됨 (73초).
